# Music

| File | What it is |
|---|---|
| `town_loop.ogg` | Placeholder town loop: 48 s, 80 BPM, D major pentatonic, koto and marimba plucks over surf (two-halves section 1). Loops by its import settings. |

Every file here is synthesized from a fixed seed by a script in `tools/`,
so it's ours under the repository's license and can be remade exactly:

```
python3 tools/make_town_loop.py content/sfw/music/town_loop.ogg
```

The real score replaces these under the same names.
